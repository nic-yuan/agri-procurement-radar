# 农产品采购决策台 —— 算法说明

面向生鲜电商（盒马 / 叮咚买菜 / 小象超市）采购岗的价格波动决策引擎。

---

## 一、设计前提

农产品价格有三个区别于工业品的特性，算法必须针对性处理，否则结论不可信：

| 特性 | 直接后果 | 应对 |
|---|---|---|
| **强季节性** | 「冬天的白菜比夏天贵」是常态而非行情；用全历史分位判断会系统性误判 | 以「往年同期 ±21 天」为**主判据** |
| **品种间波动率差异极大** | 叶菜日波动可达 10%+，粮油不足 1%；固定阈值要么天天报警、要么永不报警 | 阈值按**品种自身波动率的 Z-score** 自适应 |
| **同源多口径报价** | 同一品种有多个产地/规格报价，主产地缺报造成价格「跳变」 | 序列构建时**锁定主口径** |

### 为什么「预警」比「预测」更可靠

本工具**不做价格预测**。农产品短期价格受天气、运输、节假日、突发供需影响，任何点预测的误差都会大到无法指导采购。

工具只回答一个可验证的问题：**当前价格处在历史分布的什么位置**。这个问题有确定答案，且恰好对应采购的真实决策——「现在该多买还是少买」，而不需要知道明天涨还是跌。

## 二、数据源

| 项 | 值 |
|---|---|
| 来源 | 北京新发地市场官方价格发布页 |
| 接口 | `POST http://www.xinfadi.com.cn/getPriceData.html` |
| 频率 | 日频，当日发布（T+0） |
| 字段 | 品名、一/二级品类、最低/最高/均价、产地、规格、单位 |
| 覆盖 | 蔬菜 / 水果 / 肉禽蛋 / 水产 / 粮油 / 调料 / 豆制品 |
| 历史深度 | 单品种可回溯至 2022 年初 |
| 单日体量 | 约 475–780 条（全品种） |

**抓取参数**：并发 4、间隔 0.6s。实测并发 8 且间隔 0.05s 时源站大量返回 **503**；失败的日期不写入进度表，直接重跑即自动补抓（幂等）。

**备选源评估**：农业农村部「全国农产品批发市场价格信息系统」（pfsc.agri.cn）被放弃，原因是其 `/api/**` 由 Spring Security 的 HTTP Basic 全站保护（响应头含 `WWW-Authenticate: Basic realm="Realm"`），前端实际使用 Bearer JWT，需注册账号并持续维护登录态，合规与运维成本均高于新发地。

## 三、数据清洗与归一

### 3.1 单位归一

源站混用计价单位，只有重量单位可折算比较：

- **保留并折算**：`斤`(×1.0)、`公斤`/`千克`/`kg`(×0.5) → 统一为**元/斤**
- **剔除**：`袋`/`个`/`桶`/`箱`/`筐`/`盒`/`瓶`/`只`/`包`（约占 8%）

例如山鸡蛋 1.0 元/个、鸵鸟蛋 65 元/个，与重量计价数据不可比；生鲜电商采购主要以重量结算，剔除不影响实用性。

### 3.2 口径锁定（关键修复）

源站对同一品种同时发布多个「产地 + 规格」报价。若某天主产地缺报、只剩另一产地，价格会跳变——**这是口径变化，不是行情**。

实测影响显著：修复前菠菜出现单日 +118.6%、次日 −54.3% 的锯齿；小白菜 +117.9% 次日 −48.6%。这类信号会被误报为红色预警，直接误导采购。

处理：
1. 统计该品种出现频次最高的（产地 + 规格）组合作为**基准口径**
2. 优先采用基准口径记录；缺失时用当日全部记录的中位数兜底
3. 同日多条取**中位数**（较均值更抗个别异常报价）

### 3.3 数据断点

相邻记录间隔超过 3 天即视为断点，其「日涨跌」实为多日累计涨跌，与日频口径不同，**直接剔除**。

## 四、采购时机建议

### 4.1 指标

| 指标 | 含义 |
|---|---|
| `season_quantile` | 当前价在「过去 3 年同日历日 ±21 天」样本中的百分位 |
| `hist_quantile` | 当前价在近 3 年全样本中的百分位 |
| `vs_season_median` | 相对往年同期中位数的偏离（%） |
| `mom_7d` | 相对近 7 日均值的偏离（%） |
| `yoy` | 同比去年同期同月（%） |

### 4.2 评分

**历史 ≥ 1 年（含同期基准）：**
```
score = 0.50 × 季节分位数 + 0.30 × 全历史分位数 + 0.20 × 动量项
动量项 = 0.5 + clamp(mom_7d / 30, -0.5, +0.5)
```

**历史 < 1 年（无同期基准）**，权重转移，避免用全历史分位冒充同期分位：
```
score = 0.65 × 全历史分位数 + 0.35 × 动量项
```

### 4.3 分级与动作

| 区间 | 等级 | 动作 | 倍数 |
|---|---|---|---|
| < 0.20 | 低位 | 加量采购、适度建库存 | 1.40x |
| 0.20–0.40 | 偏低 | 小幅增量采购 | 1.15x |
| 0.40–0.60 | 正常 | 按常规量采购 | 1.00x |
| 0.60–0.80 | 偏高 | 压缩采购量、缩短锁价 | 0.80x |
| ≥ 0.80 | 高位 | 减量观望、评估替代产地 | 0.60x |

倍数指相对常规采购量的建议比例，需结合库存周转天数、损耗率与销售节奏使用。

## 五、异常波动预警

### 5.1 判据

```
r_t  = (P_t − P_{t−1}) / P_{t−1} × 100%
μ, σ = 近 60 日收益率的均值与标准差
Z    = (r_t − μ) / max(σ, 2.0)
```

`max(σ, 2.0)` 为**波动率地板**。修复前标准差趋零，导致 5.3% 的变动被算成 16.2 倍标准差、最高刷出 50.4 倍，属明显失真。

| 级别 | 触发条件（满足任一） |
|---|---|
| 🔴 一级 | \|日涨跌\| ≥ 20% 或 \|Z\| ≥ 4.0 |
| 🟠 二级 | \|日涨跌\| ≥ 12% 或 \|Z\| ≥ 2.8 |
| 🟡 三级 | \|日涨跌\| ≥ 8% 或 \|Z\| ≥ 2.0 |

当 \|Z\| ≥ 8 时分母已由地板接管，倍数不再具统计解释力，界面改用「远超该品种常态波动范围」定性表述。

### 5.2 去重

扫描窗口为最近 5 天，同一品种**只保留严重度最高的一条**（并列时取日期更新者）。更早的异动决策窗口已过，且会让同一品种反复刷屏。

### 5.3 质量标记

识别「单日剧烈变动后次日大幅反向」（\|涨跌\| ≥ 40% 且次日反向 ≥ 25%）的锯齿形态，标记 `suspect` 并降级，提示可能为口径切换或录入问题。此为启发式规则，可能误伤真实急涨急跌，故仅降级标注而非删除。

## 六、已知局限

1. **当前 3 个月历史无同期基准**：季节判据需 ≥1 年数据，现已自动降级为「全历史分位 + 动量」模式，可信度标记「中」。启用完整季节判断需以 `--days 1095` 重建历史库（耗时较长，注意限流）。
2. **单点市场**：新发地代表北京，华北以外需结合当地批发市场（江桥、白沙洲、深圳海吉星等）。
3. **批发均价 ≠ 到手价**：未含规格溢价、账期成本、物流与损耗。
4. **不做价格预测**：只判断当前价格的相对历史位置。
5. **锯齿识别为启发式**：见 5.3。
