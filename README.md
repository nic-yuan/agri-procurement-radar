# 农产品采购决策台

面向**生鲜电商采购岗**（盒马 / 叮咚买菜 / 小象超市一类）的农产品价格波动决策工具。

它不提供价格曲线供浏览，而是直接回答采购每天要做的两个决策：

1. **采购时机** —— 现在这个价贵不贵、该买多少、要不要建库存
2. **异常波动** —— 哪些品种近期出现非常态异动，需要立刻复核定价与备货

---

## 快速开始

```bash
# 1) 建库：抓取近三个月行情
python scraper/fetch_xinfadi.py

# 2) 启动服务
uvicorn api.server:app --host 0.0.0.0 --port 8000

# 3) 打开
http://127.0.0.1:8000
```

依赖见 `requirements.txt`：`requests` / `fastapi` / `uvicorn`。

## 数据源

| 项 | 值 |
|---|---|
| 来源 | 北京新发地市场官方价格发布页 |
| 接口 | `POST http://www.xinfadi.com.cn/getPriceData.html` |
| 频率 | 日频，当日发布（T+0） |
| 字段 | 品名、品类、最低/最高/均价、产地、规格、单位 |
| 分析口径 | 默认聚焦 蔬菜 / 水果 / 肉禽蛋 / 水产 |

**为何不用农业农村部 pfsc.agri.cn**：该站 `/api/**` 由 Spring Security HTTP Basic 全站保护，前端走 Bearer JWT，需注册账号并维护登录态。新发地无需鉴权、字段更完整，且本身即为国内生鲜采购的实际价格标杆。

抓取采用并发 4、间隔 0.6s 的礼貌策略（源站有限流，并发过高返回 503）。失败日期不写进度表，重跑即自动补抓。

## 算法要点

完整推导见 [`docs/算法说明.md`](docs/算法说明.md)，核心三点：

**1. 以季节分位数为主判据（权重 50%）**
农产品强季节性，「冬天的白菜比夏天贵」是常态。只看绝对价格或全历史分位会系统性误判，故主判据取「往年同期 ±21 天」的分布位置，历史分位（30%）与近 7 日动量（20%）为辅。历史不足一年时权重转移为 65% / 35%。

**2. 预警阈值按品种自身波动率自适应**
叶菜日波动可达 10%+，粮油不足 1%。固定阈值必然失效，故用相对近 60 日收益分布的 Z-score 判定，并对标准差设 2.0% 地板，避免蛋类等「价格长期恒定」品种刷出数十倍标准差的假预警。

**3. 锁定报价口径 + 剔除数据断点**
同一品种多产地/规格报价，主产地缺报会造成假跳变。算法识别主口径优先采用，同日多条取中位数；相邻记录间隔超 3 天视为断点，不参与涨跌计算。

分级动作：低位 1.4x / 偏低 1.15x / 正常 1.0x / 偏高 0.8x / 高位 0.6x（相对常规采购量）。

## 已知局限

1. **3 个月历史无同期基准**：季节判据需 ≥1 年数据，当前降级为「全历史分位 + 动量」模式，可信度「中」。启用完整季节判断需 `--days 1095` 重建库。
2. **单点市场**：新发地代表北京，华东/华南需结合当地市场。
3. **批发均价 ≠ 到手价**：未含规格溢价、账期、物流与损耗。
4. **不做价格预测**。
